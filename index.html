รหัสผ่านดูย้อนหลังไม่ได้ — ระบบเก็บเป็นรหัสที่อ่านกลับไม่ได้ มี 2 วิธีให้เขาเข้าได้อีก

วิธีที่ 1 · ส่งลิงก์ให้ครู (ง่าย แต่ใช้โควต้าเมล)
1. Supabase → Authentication → Users
2. คลิกที่อีเมลครูคนนั้น — แผงรายละเอียดเด้งขื้นมาทางขวา
3. เลื่อนลงล่างหัวข้อ Reset password → กด Send password recovery
4. ครูเช็คเมล กดลิงก์ ตั้งรหัสใหม่เอง (อย่าลืมดู junk mail)
วิธีที่ 2 · ตั้งรหัสใหม่เอง (ไม่ส่งเมล ไม่เสียโควต้า)
Supabase → SQL Editor → วางคำสั่งนี้ → Run
update auth.users set encrypted_password = extensions.crypt('OmSook1234', extensions.gen_salt('bf')) where email = 'teacher@gmail.com';
เปลี่ยน OmSook1234 เป็นรหัสใหม่ และ teacher@gmail.com เป็นอีเมลครู — แล้วบอกรหัสใหม่ทางไลน์
