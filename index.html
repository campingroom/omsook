ตั้งรหัสใหม่ให้เอง (ไม่ส่งเมล ไม่เสียโควต้า)
1. เปิด Supabase → Authentication → Users
2. ค้นหาอีเมลครูคนนั้น กดจุด 3 จุดท้ายแถว (⋮)
3. เลือก Reset password → พิมพ์รหัสใหม่ → Confirm
4. บอกรหัสใหม่ให้ครูทางไลน์ แล้วให้เขาเข้ามาเปลี่ยนเอง
ทางอื่น (ใช้โควต้าอีเมล ประมาณ 3-4 ฉบับ/วัน)
• Send password recovery — ส่งลิงก์ให้ครูตั้งรหัสเอง
• Send magic link — ส่งลิงก์เข้าระบบโดยไม่ต้องใช้รหัส
